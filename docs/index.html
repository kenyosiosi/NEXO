NEXO Engine

A non-relational DBMS built from scratch in C++17 — pages, B-Trees and a query language of its own, with an interactive desktop GUI.

Download for Windows View on GitHub

Page-based storage

Heap Files in 4096-byte slotted pages, logical deletes with tombstones and auto-compact that physically reclaims space.

B-Tree indexes

Persistent trees with a parametric minimum degree, page-aligned on disk. Secondary indexes built over live data on demand.

Query language

Tokenizer → parser → AST → executor for CREATE, INSERT, GET, UPDATE, DELETE, SCAN, INDEX, STATS, DROP and COMPACT.

Workspace GUI

Collection explorer, JSON-tree document viewer and an interactive terminal, rendered with Dear ImGui + SFML 3.

Tested & hardened

~1500 doctest assertions cover the engine; every buffer, offset and pointer is validated before it is trusted.

Portable build

CMake + FetchContent downloads SFML 3 and ImGui automatically. One command to build on Windows and Linux.

$ git clone https://github.com/kenyosiosi/NEXO.git
$ cd NEXO
$ ./build.ps1 -Test    # Windows (MSYS2 UCRT64)
$ ./build.sh --test    # Linux / WSL
